# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.2.0] — 2026-09-25

### Добавлено
- **Пуш-уведомления о новых сообщениях** с кнопками «Открыть», «Ответить», «Прочитано». Сообщения за 4 с приходят одним уведомлением. Каналы не уведомляют, группы — только упоминания (можно включить все). Чаты, заглушённые в Telegram и в боте, молчат. С 23:00 до 08:00 уведомления без звука.
- **Все вложения**: голосовые, кружки, видео, GIF, музыка, документы открываются по кнопке. В ответ можно прислать фото, голосовое, видео или файл до 20 МБ, и аккаунт отправит их от своего имени.
- **Реакции** на сообщения: поставить или убрать.
- **«📌 Непрочитанным»** и **«✓ Прочитать всё»** в списке непрочитанного и во входящих.
- **Пересылка** в любой чат: внутри аккаунта обычная пересылка, с другого аккаунта отправляется копия.
- **Поиск по всем аккаунтам сразу**: по тексту сразу по всем, а по `@username` видно, где уже есть переписка.
- **Аватарки чатов** на карточках списков и у найденного человека. Фото кэшируются на 6 часов.
- **PIN на опасные действия**: удаление сообщения, «Написать первым», пересылка, выход из аккаунта и его удаление. Хранится хэш PBKDF2 с солью. После верного PIN 5 минут не спрашивается, после 5 ошибок ввод блокируется на 10 минут. Админ может сбросить PIN пользователю.
- **Английский интерфейс** и кнопка «🌐 Язык / Language». Язык по умолчанию берётся из Telegram. Журнал показывается на языке читателя. Команды и описание бота есть на обоих языках.
- **«⚙️ Мои настройки»**: язык, тихие часы, уведомления из групп, PIN.
- **📊 Статистика в админке** за сегодня, 7 или 30 дней: действия по аккаунтам и людям.
- **Docker**: `Dockerfile`, `docker-compose.yml`, всё изменяемое хранится в томе `/data`.
- CI: проверка переводов, сборка Docker-образа и прогон стенда внутри него.
- `LICENSE` (MIT), `README.en.md`, `CHANGELOG.md`, демо-GIF.

### Изменено
- `screens/user.py` (830 строк) разнесён по модулям: `home`, `account`, `lists`, `dialog`, `actions`, `media`, `search`, `inbox`, `pin`, `common`, `fallback`.
- Ошибки Telegram и записи журнала хранятся как шаблон с параметрами и переводятся при показе.
- Без `BOT_TOKEN` бот при запуске пишет понятную ошибку вместо `KeyError`.
- Пути к `.env`, базе и логу можно задать переменными `HUB_ENV_FILE`, `DB_PATH`, `HUB_LOG_FILE`.

### Исправлено
- «Прочитать всё» берёт свежий список чатов, а не кэш, поэтому только что пришедшие сообщения тоже помечаются прочитанными.

## [0.1.1] — 2026-09-24

### Изменено
- Репозиторий открыт: README со скриншотами, CI (pyflakes + стенд на Python 3.12 и 3.14), из кода убрана личная конкретика. Адрес сервера для скриптов выкладки теперь хранится в `hub/deploy/server.local`.

## [0.1.0] — 2026-09-24

Первая рабочая версия.

- Несколько Telegram-аккаунтов в одном боте: чаты, группы и каналы, контакты, непрочитанное, входящие со всех аккаунтов.
- Ответы от имени аккаунта, «Написать первым» по `@username` или из контактов с суточным лимитом, удаление сообщений, показ стикеров и фото.
- Вход в аккаунт кнопками (код на кейпаде, 2FA), сессии зашифрованы Fernet.
- Роли на каждый аккаунт (чтение / чтение и ответы), бан, несколько админов, журнал действий.
- Карточки-картинки из HTML (Playwright), один экран — одно сообщение.
- Выкладка на свой сервер: systemd `--user`, `hubctl`, прокси Hysteria2 / VLESS / Trojan, ежедневный бэкап.
